# Muhammad Bin Asad — Quantitative Energy Portfolio

Source for [mbax0009.github.io](https://mbax0009.github.io/), an editorial portfolio focused on quantitative, explainable energy-decision tools for Pakistan.

## Featured projects

- [GreenInvest Pakistan](https://github.com/GreenInvest-Pakistan/GreenInvest-Pakistan) — household solar investment, tariff, sizing, battery, and quotation analysis.
- [Pakistan Energy Simulator](https://github.com/GreenInvest-Pakistan/Pakistan-Energy-Simulator) — utility-scale solar, wind, and wave techno-economic screening.

## Local development

```bash
npm ci
npm run dev
```

The site is built with React and Vite. Pushes to `main` are deployed automatically through GitHub Pages.
